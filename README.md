# PDF-Printing-tool

ブラウザ上で動作する、ミニマルで美しい表紙付きPDFジェネレーター＆結合・ページ調整ツールです。デジタル庁のデザインシステム（DADS）を意識したクリーンなUIを採用しています。

## 🌟 主な機能

* **① 3種類のフォントの使い分け**: `fonts/` フォルダ内の `NotoSansJP`（Medium / Bold / Light）を動的に読み込み、日本語の文字化けを防ぎつつ見出しや本文を美しくレイアウトします。
* **② Markdown風メモ入力**:
* 見出し (`#`, `##`, `###`)
* 箇条書き (`-`, `*`)
* チェックボックス (`- [ ]`, `- [x]`)
* テーブル（表形式の記述に対応）


* **③ 日付の自動挿入**: 秒単位までの正確な作成日時 (`YYYY-MM-DD HH:mm:ss`) の記載・非記載を選択可能。
* **④ 本文PDFとの結合 ＆ 4の倍数調整**:
* **そのまま（横書き用）**: 表紙を先頭にして本文をそのまま結合。
* **逆にする（縦書き用）**: 本文のページ順を逆転させ、表紙を最後に配置した上で、全体のページ数が自動的に **4の倍数** になるように先頭へ空白ページを挿入・調整。


* **⑤ プレビュー機能**: ダウンロードする前に、ブラウザのタブでPDFの仕上がりをその場で確認可能。

---

## 📁 フォルダ構成

正しく動作させるために、プロジェクトフォルダを以下のような構造に配置してください。

```text
your-project-folder/
├── index.html
├── style.css
├── script.js
└── fonts/
    ├── NotoSansJP-Bold.ttf
    ├── NotoSansJP-Medium.ttf
    └── NotoSansJP-Light.ttf

```

---

## 🚀 使い方

1. 上記のファイル構造通りにファイルを配置します。
2. `index.html` をブラウザ（Google Chrome, Safari, Firefoxなど）で直接開きます。
3. **① 表紙を作る**
* タイトルを入力。
* 日付を記入するか選択。
* メモ欄にMarkdown形式で内容を記入（表やチェックボックスも利用可能）。


4. **② PDFと結合する**
* 本文となるPDFファイルをアップロード（※表紙単体を作りたい場合は未選択でもOKです）。
* 順番（「そのまま」または「逆にする」）を選択。


5. **③ 完成！**
* **「プレビュー」** ボタンで仕上がりを確認。
* **「ダウンロード」** ボタンで完成したPDFを保存。
